## 三、写报告时的限制（修改时请保留）

- 不要把 `server/eval/data/synthetic.jsonl` 上跑出的数字写进报告。那是 12 条手写合成样例，评测脚本的 README 明确说明它上面的数字不是系统效果。
- 不要写「安全」「可以放心转账」一类保证性表述，契约禁止报告出现这类说法，项目报告也保持一致。
- 效果指标在真实测出之前保持「【待实测】」，不要用测试用例的通过率代替效果指标。740 项测试通过只说明工程行为符合预期。
- 媒体与深伪、Android 客户端这两部分在有代码提交之前保持「设计 / 开发中」，不要提前写成已完成。
